Reaction Time Game

A handheld reaction timer for Formula 1 fans. It runs the same five-light start sequence used at an F1 race start and measures how fast you react, in milliseconds. Built around a Raspberry Pi Pico microcontroller, with its own rechargeable battery, charger and a hardware switch-debounce circuit.

Timer verified against an oscilloscope: every reading within 10 ms across 10 test rounds.
